Feedback Messages

Message components provide contextual system feedback in response to user actions. The system includes success, error, and warning message variations.

Success Message

To use success message in your design, use the class .card-success for the container element. In Your HTML use class=".card-success". Use class .card-icon for the icon wrapper. In your HTML use class="card-icon". For success button use class .btn-success. In your HTML use class="btn-success". You can also use secondary button in your message. To do this apply .btn-success-secondary class to your button element. In your HTML use class="btn-success-secondary".
