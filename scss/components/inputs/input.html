Form Inputs

This Design System includes essential form input components such as labels, text inputs, textareas, select dropdowns, radio buttons, and checkboxes.

Form Control

To use form input in your design, use the class .form-group for your container. In Your HTML use class="form-group".

Labels

Use appropriate class name for your labels: class="form-label", class="form-label-error" or form-label-success".
