Form Inputs

This Design System includes essential form input components such as labels, text inputs, textareas, select dropdowns, radio buttons, and checkboxes.

Form Control

To use form input in your design, use the class .form-group for your container. In Your HTML use class="form-group".

Labels

Use appropriate class name for your labels: class="form-label", class="form-label-error" or form-label-success".

Checkbox

To create a checkbox input use the .check-container class on the container element. In your HTML, apply class="check-container" to the wrapper. Use the .checkmark class to apply custom checkbox styles from this design system. Set type="checkbox" for the input element.

Example:

To display items inline use additional class.check-container-inline. In your HTML set additional class class="check-container-inline" for your wrapper.

Example:

Radio

To create a radio input, use the .radio-container class on the container element. In your HTML, apply class="radio-container" to the wrapper. Use class="radiobtn" on the input element to apply custom radio styles. Set type="radio" for the input element.

Example:

Toggle Switch

To create a toggle switch input, use the .switch class on the container element. In your HTML, apply class="switch" to the wrapper element. Use class="switch-example" and type="checkbox" on the input element to apply toggle switch styles. Use the .slider and .round classes to create a rounded toggle slider.
