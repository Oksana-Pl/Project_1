Buttons

Primary button

To use the primary button in your design, use the class .button-primary. The styles of this class can be modified as needed in the button.scss file.

Secondary button

To use the primary button in your design, use the class .button-secondary. The styles of this class can be modified as needed in the button.scss file.

Disabled button

Make buttons look inactive by adding the disabled boolean attribute to any button element.
