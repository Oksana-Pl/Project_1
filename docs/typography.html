Typography Styles

The typographic styles of this Design System include a set of styles for headings and subheadings, styles for body text, and styles for small labels and helper text.

Hero Style

Use HERO headings for main page or section titles. Use only once per page or section.

To apply the Hero style, add the .hero class to your HTML element. In Your HTML use class="hero"

Example:

My Hero Text

Heading 1 Style

Use HEADING 1 style for primary content sections and category titles.

To apply the Heading 1 style, add the .heading1 class to your HTML element. In Your HTML use class="heading1"

Example:

This Is My Heading1

Heading 2 Style

Use Heading 2 style for subsections within a primary section.

To apply the Heading 2 style, add the .heading2 class to your HTML element. In Your HTML use class="heading2"

Example:

This Is My Heading2

Body-bold Style

Use Body-bold style for emphasizing key information within paragraphs.

To apply the Body-bold style, add the .body-bold class to your HTML element. In Your HTML use class="body-bold"

Example:

This text in bold

Body-text Style

Use Body-text style for body text on the page.

To apply the Body-text style, add the .body-text class to your HTML element. In Your HTML use class="body-text"

Example:

This is regular text on your page

Label Style

Use Label style for labels and pop-ups

To apply the Label style, add the .label class to your HTML element. In Your HTML use class="label"

Label text here

Use Caption style for captions and hints.
