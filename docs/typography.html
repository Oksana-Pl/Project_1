Typography Styles

The typographic styles of this Design System include a set of styles for headings and subheadings, styles for body text, and styles for small labels and helper text.

Hero Text Style

Use HERO headings for main page or section titles. Use only once per page or section.

To apply the Hero style, add the .hero class to your HTML element. In Your HTML use class="hero"

Example:

My Hero Text

Heading 1 Text Style

Use HEADING 1 style for primary content sections and category titles.

To apply the Heading 1 style, add the .heading1 class to your HTML element. In Your HTML use class="heading1"

Example:

This Is My Heading1

Heading 2 Text Style

Use Heading 2 style for subsections within a primary section.

To apply the Heading 2 style, add the .heading2 class to your HTML element. In Your HTML use class="heading2"

Example:

This Is My Heading2
