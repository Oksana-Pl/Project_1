Design System

This is a minimal e-commerce design system created for modern online retail interfaces. It provides reusable styles and components that help speed up development while maintaining consistency.

What’s included

This design system includes:

  • Color system (primary, secondary, neutral and feedback palettes)
  • Typography styles for desktop and mobile
  • Spacing system based on consistent scale
  • UI components (buttons, inputs, feedback messages)
  • Usage guidelines for implementation
